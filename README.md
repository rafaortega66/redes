# Redes

Sitio estático con apuntes de redes de datos: seguridad de la información y
direccionamiento IPv4, aplicados a una red doméstica.

Publicado con GitHub Pages: https://rafaortega66.github.io/redes/

## Estructura

- `index.html`: portada.
- `marco-teorico.html`: marco teórico (seguridad de la información y direccionamiento IPv4).
- `assets/style.css`: estilos, los mismos del sitio de apuntes.
